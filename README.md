KIKU PROPOSAL WEBSITE 💗

FILES
- index.html: the complete website (HTML, CSS and JavaScript are included).
- photos/: put your photos in this folder.

ADD YOUR PHOTOS
1. Choose up to three photos you have permission to share.
2. Rename them exactly:
   photo1.jpg
   photo2.jpg
   photo3.jpg
3. Put them in the photos folder, replacing this README if needed.
4. If your pictures are PNG files, either convert them to JPG or edit the image filenames in index.html.

PREVIEW ON YOUR COMPUTER
- Easiest: open index.html in Chrome or Edge.
- For a better development setup, install Visual Studio Code and the Live Server extension, then right-click index.html > Open with Live Server.

PUBLISH WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a new public repository, e.g. kiku-proposal.
3. Upload index.html and the photos folder (including your photo files).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for the published URL shown in the Pages section. It will usually look like:
   https://YOUR-USERNAME.github.io/kiku-proposal/
7. Open the URL on your phone to test it before sharing.

PRIVACY TIP
A public GitHub Pages site can be viewed by anyone with the link (and may be discoverable). Don't upload private/intimate photos or personal details. Ask for consent before sharing photos of someone else. The proposal should feel playful, not pressuring: you can change the button text or remove the runaway behavior if you'd prefer.

CUSTOMIZE THE MESSAGE
Search in index.html for "Dear Kiku" and edit the paragraphs to sound like you. Keep the proposal sincere and low-pressure.
